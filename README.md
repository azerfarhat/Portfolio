# Azer Farhat portfolio (Next.js)

Next.js (App Router) + React. No other dependencies.

## Run it
```bash
npm install
npm run dev      # http://localhost:3000
```

## Build for production
```bash
npm run build
npm start
```

## Deploy
Push the folder to GitHub and import it on Vercel. No settings needed.

## Edit your content
- Projects, studies and tools: `app/data.js`
- Texts and layout: `app/page.jsx`
- Styles: `app/globals.css`
- Portrait: replace `public/portrait.jpg` (keep a 4:5 ratio, for example 800x1000)
